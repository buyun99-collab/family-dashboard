# 우리 가족 기록장

아빠 · 엄마 · 하진 · 우재, 네 사람이 함께 쓰는 휴대폰용 가족 기록장입니다.
**파일 하나(`index.html`)**로 동작하고, 가족 모두의 휴대폰에서 **같은 기록을 실시간으로 함께** 봅니다.

- 주소: <https://buyun99-collab.github.io/family-dashboard/>
- 휴대폰 Chrome에서 열고 메뉴 → **홈 화면에 추가**를 하면 앱처럼 아이콘이 생깁니다.

## 처음 들어갈 때 — 가족 암호

- 처음 한 번 **가족 암호(숫자 6자리 이상)**를 누르면, 그 기기에서는 다음부터 다시 묻지 않습니다.
- **가족 암호는 이 저장소 어디에도 적혀 있지 않습니다.** 암호는 가족에게만 따로 전해 드렸으니, 가족끼리만 기억해 주세요.
- 암호를 잊어버리면 그 기기에서는 기록이 보이지 않습니다. ⚙️ 설정 → **가족 암호 → 암호 변경**에서 두 번 입력해 바꿀 수 있고, 바꾸면 **다른 기기에서는 새 암호로 다시 들어와야** 합니다(기록은 그대로 옮겨집니다).

### 어떻게 잠기는가

- 입력한 암호는 어디에도 저장하지 않습니다. 브라우저 안에서 **SHA-256 해시**로 바꾼 값만 데이터베이스 주소의 일부로 씁니다.
- 그래서 이 페이지의 소스(HTML)나 저장소를 봐도 데이터베이스 경로를 알 수 없고, 암호를 아는 가족만 기록에 닿습니다.
- 데이터베이스 규칙도 **루트는 읽기·쓰기 모두 막고, 암호 해시 경로 하나만** 열어 두었습니다.

## 다섯 화면

| 탭 | 내용 |
| --- | --- |
| 홈 | 가족 4명 요약(별·돼지저금통), 오늘의 가족 미션, 하진·우재 도장판(요일별·연속 일수·달력 보기) |
| 공부 | 아이별 오늘의 공부 플랜, 진행률, 체크하면 용돈 적립과 도장이 바로 반영, 고정 항목 관리, 공부 타이머 |
| 용돈 | 시작 금액 + 공부 적립 + 입금 − 사용 자동 계산, 입금·사용 기록, 요일별 적립 막대 |
| 할일 | 하진·우재·엄마·아빠 각자의 할 일 체크·추가·수정·삭제 |
| 채팅 | 보내는 사람 전환(이 기기에서 고른 사람을 기억), 말풍선, 가족 캐릭터 스티커, 하트 반응 |

## 실시간으로 함께

- 공부 체크·도장·용돈 기록·할 일·채팅이 **가족 모두의 기기에 바로** 나타납니다(Firebase Realtime Database).
- **인터넷이 잠깐 끊겨도** 화면은 그대로 쓸 수 있고, 그동안 바꾼 내용은 이 기기에 저장됐다가 다시 연결되면 가족 모두에게 반영됩니다.
- 채팅에서 **누구로 보낼지** 고르면 그 기기가 기억합니다. (기기마다 다르게 정할 수 있어요.)
- 자정이 지나면 공부 목록은 고정 항목만 남고 다시 시작하며, 가족 미션도 새로 뽑힙니다. 어느 기기가 먼저 날짜를 넘겨도 같은 날짜로 맞춰집니다.

## 날씨

화면 위 배지는 **통영의 실제 날씨와 미세먼지·초미세먼지 등급**을 보여 줍니다(Open-Meteo, 10분마다 새로 고침). 인터넷이 없으면 "날씨를 불러오지 못했어요" 안내로 바뀝니다.

## 기록 지우기 · 내보내기

- ⚙️ 설정 → **기록 내보내기**: 지금까지의 기록을 JSON 파일로 내려받습니다.
- ⚙️ 설정 → **모든 기록 초기화**: 두 번 누르면 처음 상태로 돌아갑니다. **가족 모두의 기록이 함께 지워지니** 필요할 때만 쓰세요.

## 배포 메모 (나중에 고칠 때)

- GitHub Pages는 이 저장소의 **`gh-pages` 브랜치**를 보고 있습니다. `index.html`을 고치면 `main`과 `gh-pages`에 함께 올려 주세요.
- 날씨·동기화가 처음부터 안 되면: Firebase 콘솔의 Realtime Database 규칙과 인터넷 연결을 확인해 주세요.
- 암호를 아무리 넣어도 "암호가 맞지 않아요"가 나오면: 데이터베이스에서 그 암호의 해시 경로에 `initialized: true`가 있는지 확인해 주세요. 잠금 해제 기준이 이 표시입니다.

## 이 기록장에 담지 않은 것

이름(성), 전화번호, 집 주소는 넣지 않았습니다. 화면에 나오는 것은 `아빠`·`엄마`·`하진`·`우재` 뿐입니다.
가족 기록은 가족 암호의 해시 경로에만 보관합니다. 다만 인터넷에 공개된 페이지인 만큼, 암호는 가족 밖에 알려 주지 마세요.
